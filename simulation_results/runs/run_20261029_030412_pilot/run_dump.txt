  hub          the Clawnly matchmaker (orchestrator), claude-opus-5-5. It plans groups and talks to each agent one to one.
  agent        one emulated person's own AI, claude-sonnet-5. It knows only that person's profile and answers for them.
               Agents never talk to each other. Each agent call is a fresh conversation: no memory.
  break room   a pool code builds per activity and time of day: everyone free, interested, within
               budget and not avoiding anything about it. The hub may only invite from it.
  keenness     how much a person likes the activity's tags (likes are weighted 1-3).
  round 1 / 2  round 1 asks everyone the plan proposed; round 2 asks only who the hub re-asks after
               the resolve step (alternates for a no, people whose time changed).
  yes/no/counter  an agent's answer; a counter proposes one change.
  locked       code confirms a group once 2+ people said yes; dropped otherwise.
  code showed the agent   what matchmaker.plan_checks found in the profile against the plan.
