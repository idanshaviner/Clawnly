# Matchmaker skill: who belongs in a group

This file is read by the matchmaker on every run, on the server and on the Run Clawnly page.
It grows: every weekday Ashish, Eitan and Idan label a few example groups Keep or Change in the
shared review sheet, and each kept example is added below in the same simple Good / Bad format.
Use it as judgment, not as a rule book: code already checks who is free, interested, can afford
it and avoids nothing about it.

## Stage of life

- Judge whether the people in a group are in a similar chapter of life: students, young
  professionals, parents of young kids, empty nesters, retirees.
- As a rough guide, keep members within about 10 years of each other. This is judgment, not a
  locked rule: a slightly wider spread can work when everything else lines up.
- A shared interest alone does not make a 19-year-old and an 83-year-old a good small group.
- Exception that can be okay: a parent and a teen together at a clearly family-style event.

## Main thing vs side thing

- Seat people who like the activity's main thing. Trivia night is for trivia fans, cribbage is
  for card players, a hike is for hikers.
- People there for a side thing (the beer at trivia, the coffee at cribbage, the river near a
  hike) are backups (alternates), not the core group.
- Describe the activity honestly in every proposal: don't pitch a hike as river access to win
  over anglers.
- When a group fails because the activity was wrong for those people, swap the activity, not
  the people.

## A no is a signal

- When someone says they wouldn't meet a specific person again, don't put that pair in the
  same small group again. It is about the pair, not a strike against either person: each can
  still be placed with other neighbors.
- When someone declines an activity, ask whether the activity was wrong before deciding the
  people were wrong.
